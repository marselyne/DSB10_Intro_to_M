# DSB10 — Intro to ML

Проект по изучению основных алгоритмов машинного обучения для задач классификации, регрессии и кластеризации.

## 📌 О проекте

В рамках проекта были исследованы различные алгоритмы Machine Learning и методы оценки качества моделей.

Проект охватывает:
- binary classification
- multiclass classification
- regression
- clustering
- cross-validation
- model evaluation

---

## 🚀 Реализованный функционал

### 🔹 Binary Classification

Исследованы модели:
- Logistic Regression
- Support Vector Machine (SVM)
- Decision Tree

Проведено:
- обучение моделей
- сравнение accuracy
- анализ ошибок классификации

---

### 🔹 Multiclass Classification

Реализованы:
- multiclass classification
- one-hot encoding
- работа с категориальными признаками

---

### 🔹 Cross Validation

Изучены:
- train/test split
- cross-validation
- оценка устойчивости моделей
- предотвращение overfitting

---

### 🔹 Regression

Исследованы:
- regression models
- оценка качества предсказаний
- анализ ошибок

---

### 🔹 Clustering

Изучены методы кластеризации:
- K-Means
- анализ кластеров
- визуализация распределений данных
